Publish throwaway, commit-pinned copies of Jenkins jobs from your own fork, run them, tear them down. No pull request needed. Production jobs are never reachable. Six tutorials, each with the real session on top and what the controller does underneath.

Start here, no pull request needed. The tool is the script. Seven lines, then the tour: 
uv tool install git+https://github.com/nogueiraanderson/jenkins-preview
export JENKINS_URL=https://ps3.cd.percona.com
export JENKINS_USER=<your jenkins user id>
export JENKINS_TOKEN=<token from /me/configure>
# or once: ~/.config/jenkins-preview/credentials.yaml (chmod 600, layout in the README)
cd ~/jenkins-pipelines && git checkout my-branch
jenkins-preview sets --example > .jenkins-preview.json
jenkins-preview doctor
The sets file is the committed JSON naming which jobs form a set. Tutorial 2 shows the one refusal you will meet first, and why it protects exactly the change you are testing.
